# План монетизации — EUDR Compliance Assistant

**Дата:** 2 июля 2026 · **Статус продукта:** ближе всех к боевому — полный цикл
EUDR-комплаенса (сбор геоданных → валидация → риск-оценка → DDS → экспорт в TRACES),
217 тестов, CI, биллинг-каркас, EN/DE-локализация, аудит-лог.

## Почему именно этот продукт

- **Рынок горит прямо сейчас.** EUDR обязывает операторов (кофе, какао, соя, пальмовое
  масло, каучук, древесина, КРС) подавать Due Diligence Statement. Дедлайны применения
  уже наступили/наступают для разных категорий компаний — тысячи малых импортёров в ЕС
  ищут инструмент «здесь и сейчас». (Первый шаг плана — проверить актуальные даты
  применения после переносов 2025 г. и построить месседжинг вокруг ближайшего дедлайна.)
- **Продукт решает задачу целиком**, а не кусок: конкуренты уровня osapiens/Live EO
  целятся в enterprise с ценником от тысяч евро; ниша SMB (€49–199/мес) почти пуста.
- **Кодовая база реально production-grade**: строгий TS, зелёный quality-gate,
  безопасность (JWT-ротация, rate-limiting, аудит), i18n DE — критично для целевого
  рынка Германии.

## Чего не хватает для монетизации (приоритизировано)

### Блокеры выручки (без этого денег нет)
1. **Реальные платежи.** `POST /api/account/plan` меняет тариф бесплатно, без
   платёжного провайдера. Нужен Stripe Checkout + Customer Portal + webhook
   (или Paddle как merchant-of-record — сам решает вопрос EU VAT, лучший вариант
   для соло-фаундера без юрлица в ЕС).
2. **Продакшн-деплой**: домен, Vercel + управляемый Postgres (Neon/Railway),
   R2-бакет, верифицированный домен в Resend.
3. **Юридический минимум для B2B в ЕС**: Privacy Policy, Terms of Service,
   Impressum (обязателен для DE!), GDPR/cookie-баннер, шаблон DPA. Немецкая
   компания не оплатит SaaS без Impressum и DPA.
4. **Сброс пароля и верификация email** — отсутствуют; базовая гигиена, без
   которой первый же платящий клиент застрянет.

### Ускорители конверсии
5. **Trial-механика**: тариф TRIAL не ограничен по времени — ввести 14 дней,
   баннер обратного отсчёта, серия из 4 onboarding-писем, upgrade-подсказки в
   момент упора в лимит (3 поставщика).
6. **Годовая оплата** (−20%) и пересмотр сетки: Starter €49 / Professional €199
   адекватны; добавить overage или «Pro+» на 500 поставщиков.
7. **Командный доступ (seats)**: сейчас 1 аккаунт = 1 логин; B2B покупает
   компания — минимум «до 3 пользователей» на Professional.
8. **Лид-магнит без регистрации**: публичная страница «бесплатная проверка
   GeoJSON на соответствие EUDR» (движок `eudr-validator.ts` уже есть) —
   SEO-трафик + вход в воронку.

### Яркость / дифференциация
9. **Сателлитная проверка вырубки** (Global Forest Watch / GLAD alerts API) по
   полигонам поставщиков — превращает «калькулятор риска» в «доказательство», и
   это главный wow-фактор демо.
10. **Прямая подача DDS в TRACES** (EU Information System API) — сейчас JSON-выгрузка;
    прямая интеграция = killer-feature и повод для Enterprise-ценника.
11. **Наблюдаемость и доверие**: Sentry, Plausible/PostHog, status page, страница
    Security. Соцдоказательство: 2–3 пилотных кейса (можно бесплатных за отзыв).

## Неделя запуска

### Только вы (≈ 3–4 часа за неделю + звонки)
| День | Действие | Почему только вы |
|---|---|---|
| Пн | Купить домен (например `eudrassistant.com`); создать prod-аккаунты Vercel + Neon/Railway + Cloudflare R2, выдать env-переменные | Владение аккаунтами и оплата |
| Пн | Зарегистрировать Paddle **или** Stripe (KYC: паспорт, реквизиты) и решить: MoR (Paddle) vs Stripe | KYC проходит только владелец |
| Вт | Подтвердить DNS-записи Resend для домена; утвердить финальные цены | Доступ к DNS; решение о ценах |
| Ср–Пт | Отправить 20–30 персональных сообщений в LinkedIn по моим шаблонам (ICP: импортёры кофе/какао DE/NL/BE 5–50 сотрудников, таможенные брокеры, EUDR-консультанты) | Личный профиль = доверие |
| Ср | Записать 2-мин Loom-демо по моему сценарию (живой голос продаёт лучше) | Ваше лицо/голос |
| Ежедн. | Отвечать на входящие, проводить демо-звонки, предложить 3 пилотам «бесплатно за кейс+отзыв» | Продажи — это вы |

### На мне (делаю по мере готовности доступов)
- **Пн–Вт:** интеграция платежей (Stripe Checkout + Portal + webhooks в тест-режиме,
  переключение на live одним env); enforcing trial 14 дней.
- **Вт–Ср:** password-reset + email-verification флоу; onboarding-серия писем (Resend).
- **Ср:** страницы Privacy / Terms / Impressum / DPA (EN+DE, драфты под вашу проверку);
  cookie-баннер.
- **Чт:** публичный бесплатный EUDR GeoJSON-checker (лид-магнит) + SEO-мета,
  OG-картинки, 3 контентные страницы («EUDR для импортёров кофе» и т.п.).
- **Пт:** Sentry + Plausible; сценарий демо-видео; шаблоны LinkedIn/email-аутрича EN/DE;
  годовые тарифы в биллинге.
- **Следующая итерация:** Global Forest Watch-проверка, multi-user seats, TRACES API.

## Правила на эту неделю
1. Ни одной новой фичи, пока не принят первый платёж (исключение — блокеры №1–4).
2. Каждый день — минимум 5 новых касаний с потенциальными клиентами.
3. Пилотам продаём «результат»: готовый к подаче DDS, а не «доступ к софту».
4. Цену не обсуждаем скидками — даём расширенный триал.
5. Все ответы рынка (возражения, вопросы) фиксируем — это бэклог следующей недели.

**Цель недели:** прод в бою, платежи включены, 3 пилота в системе, 1 оплаченная подписка.
